# 工作台体验与实用工具增强

日期：2026-09-09

## 如何使用

重启现有启动器管理的工作台服务，然后刷新页面。首页和项目侧栏均可进入“实用工具”。无需新依赖或数据库迁移；现有项目继续使用原数据库。

网络工具先选择项目，再输入域名、IP 或 URL。成功后可以复制结果、下载 JSON，或将目标加入项目资产。加入资产仅保存目标主机，不自动创建漏洞、保存响应正文或导入 DNS 返回的所有地址。

| 工具 | 行为 |
| --- | --- |
| DNS 解析 | 系统解析器查询 IPv4 / IPv6；不包含 MX、TXT 等记录查询 |
| HTTP 响应头 | 一个 HEAD 请求，不跟随重定向，不下载正文；展示白名单响应头；验证 TLS；遵循项目代理 |
| TLS 证书 | 验证证书并展示协议、颁发者、有效期与域名；直连 |
| 端口连通性 | 建立一次 TCP 连接后关闭；单端口，直连 |
| IP / 网段计算 | 网络范围、版本、地址总数、私有地址属性 |
| URL 解析 | 主机、端口、路径与参数名；输出隐藏查询参数值 |
| JSON 格式化 | 校验并格式化 JSON |
| Base64 解码 | 将有效 Base64 解码为 UTF-8 文本 |
| SHA-256 | 计算输入文本的 UTF-8 摘要 |

网络动作重新检查项目授权范围，有超时和每个 Web 进程最多 4 个并发诊断的限制。诊断不执行外部命令。自 2026-09-10 起，网络成功动作写入任务摘要并保存有大小限制的脱敏诊断证据，便于继续验证和 AI 解读。本地处理工具的输入和结果不写入数据库。新增能力见 [单兵工作台说明](SOLO_WORKBENCH.md)。

## 界面与流程

- 统一单侧导航，常用的资产、请求、证据和报告入口直接可见。
- 分析与 AI、设置与备份默认收起；打开相应页面时展开所在分组。
- 首页围绕继续项目、排查问题、整理数据三个入口组织内容。
- 项目首页增加收集资产、检查目标、验证问题、整理交付四步导航。
- 专业技能和分析概览默认收起。
- 字号、按钮点击区域、间距、焦点提示统一调整；窄屏使用可展开导航。
- 工具输入、运行中、成功、错误、复制和下载均有独立状态提示。

## 可靠性与性能

- 草稿保存串行执行，失败后延时重试，恢复网络后重试，离开页面前提示尚未保存的修改。
- 搜索响应校验请求序号，旧响应不能覆盖当前结果。
- 接口列表仅查询数据；请求创建、编辑、导入仍执行原有增量同步。
- 接口和漏洞列表每页 50 条，顶部搜索覆盖所有记录。表格快捷筛选、排序、CSV 导出仅作用于本页。
- 路由候选区最多显示最近 100 条；项目统计仍展示总量。
- 漏洞评分批量加载关联数据，20 条漏洞的评分汇总实测固定 6 次查询；不加载证据正文用于评分。
- 首页卡片通过分组查询计算统计，避免每个项目重复调用完整工作台统计。
- 备份失败写入错误记录，备份页不再显示无效下载入口，后台记录失败日志。
- 测试连接使用临时数据库和临时附件目录；页面测试禁用自动备份调度。
