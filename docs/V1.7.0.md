# 雪锋 SnowEdge V1.7.0

<p align="center"><img src="../app/static/brand/snowedge-app.png" width="96" alt="SnowEdge"></p>

本轮优先补齐人工漏洞工作流、发布隔离和本地界面防护，保留已有数据。

## 人工漏洞处理

从「发现 → 手工新建漏洞」录入标题、目标、风险等级、类型、参数、描述和复现步骤、修复建议、CWE、OWASP 与 txb02 分类。已有自动发现也可编辑，原始检测指纹保持不变，避免扫描重复创建同一漏洞。分类清空后不会被自动回填。

详情页可添加证据说明、关联本项目已有证据、上传截图、标注截图，记录「仍可复现 / 确认已修复 / 结果待核实」。编辑与人工验证留下记录；并发编辑会提示冲突并保留输入。最新字段进入报告，人工复测状态不再被“未创建自动验证包”覆盖。

## 项目与工作流程

项目设置可修改项目名、客户、日期、授权说明与范围。先预览再确认，确认内容绑定当前版本；修改范围前必须等待运行中的任务停止，旧排队任务取消。修改记录可在编辑页查看。

常用导航为：工作台、资产、扫描中心、请求、权限测试、发现、证据、报告。工具、解码和 AI 高级能力放入次级导航。旧评估入口转到扫描中心并填入目标草稿，需要在扫描中心发起任务。历史任务保留供查询。

## 凭据和代理

个人设置提供清除并停用 AI Key、撤销 Burp 令牌、重新生成令牌。清除 AI Key 同时禁止回退到旧环境配置；不会改写用户的原始配置文件。新 Burp 令牌只在生成响应显示，页面禁止缓存。

扫描中心提供代理管理入口，可切换、停用、重新启用、删除配置与密码、向授权地址测试连接。仍被项目或全局默认引用的配置不能直接禁用或删除。失效代理报错，不自动直连。最近使用记录覆盖扫描任务与管理页连接测试，不代表其他模块的完整网络审计。

## 本地防护

默认仅接受 localhost、127.0.0.1、::1 Host，状态修改请求验证浏览器 Origin 与 Fetch Metadata。跨来源、null Origin 和可疑 Host 会被拒绝。无浏览器来源头的本机 API 客户端仍兼容；本版未新增统一 API 会话令牌。OOB 回调继续使用独立的限时随机关联令牌。

有意通过其他域名部署时，需显式配置 LOCAL_ALLOWED_HOSTS；反向代理应正确转发来源信息。扫描能力边界见 SCAN_CENTER.md。

## 干净发布与首次启动

正式 ZIP 通过文件白名单生成，只保留 SnowEdge.exe 一个启动入口及必要代码、静态资源、迁移与运行库。不带 .env、数据库、备份、日志、历史证据、运行目录、开发虚拟环境、测试、SDK、旧启动器和 PDB。release-manifest.json 记录文件摘要。

首次启动需要已安装 Python 3.11+ 并加入 PATH、WebView2 和可用网络，自动创建本机虚拟环境及安装依赖；这不是自带 Python 的完全离线安装包。安装失败可查看 .runtime/setup-error.log，重新启动可重试。运行后自动生成本安装独有的 .runtime/app-secret；已有 APP_SECRET_KEY 配置保持优先，避免破坏旧数据解密。

已有用户应先保存原目录并创建加密完整备份，在新目录验证恢复后再迁移。不要删除旧 .env 或应用密钥。完整备份会将应用密钥纳入加密备份，普通脱敏项目导出不等同于完整迁移。

窗口关闭时回收自己创建的服务；复用已有服务时不接管其生命周期。支持窗口缩放及显示大小设置。托盘和任务通知尚未加入。

## 验证范围

回归测试使用隔离数据库；浏览器检查覆盖桌面、窄屏、扫描草稿、范围拦截、暂停以及人工漏洞录入与证据。独立发布测试目录实际创建了全新运行环境、安装依赖，并通过原生 WebView2 启动、缩放、关闭、已有服务复用及进程异常回收检查。

没有用真实付费测绘账户或公网 OOB 服务进行验收，也没有在另一台物理电脑上验证。本版本未宣称可替代完整 Nmap、Nuclei、Tscan 或 Burp。
