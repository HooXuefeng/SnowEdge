Public references reviewed while designing V0.6:

1. AboutSecurity
   - https://github.com/wgpsec/AboutSecurity
   - Security methodology knowledge base with agent-readable Skills.

2. Anthropic Cybersecurity Skills (community)
   - https://github.com/mukul975/Anthropic-Cybersecurity-Skills
   - Large agentskills.io-style cybersecurity Skill catalog.
   - The repository states it is a community project and not affiliated with Anthropic PBC.

3. CAI
   - https://github.com/Owami/cai-cybersecurity
   - Cybersecurity-oriented agent framework with Agents, Tools, Handoffs, Tracing, and HITL concepts.

4. PentestGPT
   - https://github.com/GreyDGL/PentestGPT
   - Autonomous pentest framework with staged execution and deterministic trace/scope/evidence concepts.

5. AI Pentest Agent
   - https://github.com/Erfix404/ai-pentest-agent
   - Example agent Skill packaging with SKILL.md and SKILL.yaml.

The V0.6 release does not automatically download or execute third-party scripts, payloads, or offensive command sequences from these repositories.
