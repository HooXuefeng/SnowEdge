## 从工具结果进入研判

请求工作台选中请求后，点击「AI 研判与工具联动」。证据中心选择记录后也有同名入口；漏洞详情页可对当前漏洞进行分析。

页面提供 AI 分析、返回请求编辑与重放、权限对比、目标带入扫描中心和记录漏洞草稿。扫描动作只创建目标草稿，仍需在扫描中心选择阶段并启动。重放与权限验证沿用已有工具的范围、代理及任务约束。

AI 通过现有 Copilot 任务队列执行，明确传入当前来源与最近响应、关联证据。提示按事实、假设、缺口、下一步操作、报告与修复建议区分输出。结构化和嵌套 JSON 中的常见凭据先脱敏；外部观察内容视为不可信数据。AI 返回的命令不执行，只保留允许的引用及分析结果。未配置实际服务时清楚显示演示模式。

「将研判带入漏洞草稿」打开可编辑表单。用户核对内容后保存为候选漏洞，工具来源作为独立证据快照关联。AI 不会直接修改或确认原漏洞，也不会自动提交报告。

## 报告交付

报告中心新增「选择漏洞与交付快照」。支持：

- 客户版：漏洞说明、分类、复测状态及证据编号和摘要。
- 内部技术版：增加脱敏证据摘录。
- 复测版：增加人工复测证据摘录。

按漏洞勾选纳入报告，可选择包含已经人工检查敏感信息的截图与标注。快照保留未确认、缺少证据、缺少修复建议等提示，之后可下载 Word、HTML 或 Markdown。

快照内容与截图保存在本地数据库中；修改项目或漏洞后，旧快照仍保留原内容。下载时校验快照摘要。单次最多 200 条漏洞、截图合计 12 MB、总快照 24 MB。证据摘录有长度限制，完整原始证据仍在证据中心。截图不会自动识别或抹除敏感信息。

HTML 为独立文档，截图内嵌；Markdown 也采用内嵌图片，部分 Markdown 阅读器可能不支持。Word 不依赖图片的原始路径。三个报告类型是固定内容策略，尚不是可视化模板设计器。

## 外部工具边界

复用已有 Burp 请求/扩展接入、Nmap XML 导入和 Nuclei JSONL 导入；内置扫描继续支持声明的 Nuclei HTTP 模板子集。此版本没有新增外部 Nmap/Nuclei 任意命令执行、完整自主工具循环或 MCP 工具服务器。

## 验证

完整回归 191 项通过；新增测试覆盖定向来源与响应、嵌套凭据脱敏、项目隔离、候选漏洞证据关联、队列复用、扫描草稿、固定快照、截图进入 Word、三个导出格式与完整性检测。桌面/窄屏页面通过实际浏览器检查。

AI 验证采用模拟提供者与演示模式，未调用用户真实付费模型；外部工具仍沿用此前已明确的验收范围。
